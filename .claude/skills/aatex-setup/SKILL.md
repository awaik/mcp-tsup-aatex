# Настройка MCP ЦУП ААТех

## Когда использовать

- Первый запуск проекта (пользователь только скачал папку)
- Пользователь просит: «подключи MCP», «настрой ИИ», «проверь связь»
- Инструменты `mcp__aatex-cup__*` не видны / не отвечают
- После смены ключа, истечения токена, перезапуска клиента

## Диагностика: проверь до начала

1. **Есть ли файл `.mcp.json` в корне проекта или `~/.claude.json`?**
   - Если нет — нужна полная настройка
   - Если есть — проверь Authorization header

2. **Попробуй вызвать `list_spaces`:**
   - Работает → всё хорошо, покажи что ещё умеет
   - `401 Unauthorized` → ключ не валиден
   - `403` → ключ не от этой организации
   - Инструмент не найден → клиент не подгрузил MCP-сервер

## Шаги настройки

### Шаг 1. Получить ключ

Скажи пользователю:

> Чтобы я мог работать с ЦУП ААТех, нужен API-ключ. Получи его так:
>
> 1. Зайди на https://app.aatex.ru и выбери нужную организацию
> 2. Открой **Профиль → Подключить ИИ (MCP)**
> 3. Нажми **«Создать ключ»**
> 4. **Сразу скопируй его** — показывается только один раз
>
> Вставь ключ в чат, я настрою конфиг.

### Шаг 2. Сконфигурировать клиент

Создай `.mcp.json` в корне проекта:

```json
{
  "mcpServers": {
    "aatex-cup": {
      "type": "http",
      "url": "https://app.aatex.ru/mcp",
      "headers": {
        "Authorization": "Bearer ВСТАВЬ_КЛЮЧ_СЮДА"
      }
    }
  }
}
```

**Важно:** добавь `.mcp.json` в `.gitignore` если в проекте есть git — ключ не должен попасть в репозиторий.

### Шаг 3. Перезапустить клиента

- **Claude Code** — выйти и запустить заново в этой папке
- **Claude Desktop** — Settings → MCP → Reload (или перезапуск приложения)
- **Cursor** — Reload Window

После перезапуска должны появиться 57 инструментов `mcp__aatex-cup__*`.

### Шаг 4. Проверить связь

Вызови `list_spaces` — должен вернуть массив пространств. Если ответ непустой — всё работает, скажи пользователю что готов к задачам.

## Типичные ошибки

| Симптом | Причина | Что сделать |
|---------|---------|-------------|
| `Missing or invalid Authorization header` | Ключ не передан / кривой формат | Проверь что в конфиге `"Bearer ключ"`, а не просто `"ключ"` |
| `401 Unauthorized` + `Invalid or expired access token` | Ключ отозван или неправильный | Создай новый через UI |
| `Not a member of this organization` | Ключ от другой организации | Создай ключ в нужной орге |
| `403 Session belongs to another user` | Осталась сессия от прежнего пользователя | Перезапусти клиента полностью |
| Инструменты `mcp__aatex-cup__*` не видны | Клиент не подхватил конфиг | Проверь путь к `.mcp.json`, перезапусти |
| `File too large` | Загружается файл > 20 МБ | Используй UI или разбей на части |
